# Черновики интеграции (не устанавливаются)

`ribbon.template.xml` — концептуальный список UX-команд, **не валидный CUIX и не схема nanoCAD**. `evakuator.package.template` — перечень будущих компонентов, **не** установочный пакет. Сборка настоящего `.package` / `.cuix`, их schema, автозагрузка и регистрация зависят от версии лицензированного SDK и должны быть реализованы и проверены в nanoCAD согласно `docs/NANOCAD_SDK_INTEGRATION_GUIDE.md`. В репозитории нет привязанных обработчиков EVAC-команд. Нельзя считать эти шаблоны функциональной интеграцией.
