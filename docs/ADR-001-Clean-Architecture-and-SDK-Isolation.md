# ADR-001: Чистое ядро и изоляция nanoCAD SDK

**Статус:** принято для учебного прототипа, 2026-10-26.

## Контекст
Реальных `mapimgd.dll`, `hostdbmgd.dll`, `hostmgd.dll`, версии nanoCAD и лицензированного хоста в репозитории/окружении не обнаружено. Сигнатуры и поддерживаемый хостом CLR нельзя надёжно вывести из названий. Нельзя использовать фальшивые типы, чтобы создать видимость работающего плагина.

## Решение
`Domain → Norms/Geometry → Validation → CadAdapter → UI/CliDemo`: бизнес-логика и геометрия не импортируют proprietary API. `ICadDocumentContext` задаёт неизменяемый снимок, оптимистическую транзакцию по ревизии, undo и уведомления. `InMemoryCadDocumentContext` — рабочий **симулятор**, не эмулятор DWG и не замена nanoCAD. Он имеет bounded undo 100, не теряет обновления при проверке ревизии, изолирует ошибки слушателей после успешного коммита. Уведомления конкурирующих транзакций могут приходить не по порядку; UI перечитывает актуальный снимок.

Отдельные `EvacSignCustomObject`, `EvacPathCustomObject` и `EvacLegendCustomObject` редактируют domain-модели. Их имена не означают наследование от `McCustomBase`. Настоящий мост потребует проверки механики транзакций, преобразований, регистрации, сериализации, жизненного цикла и поддерживаемого target framework. `#if NANOCAD_SDK` в `SdkGate.cs` блокирует ложноположительную сборку до написания и тестирования моста. Контракты не гарантируют, что конкретный CAD-хост реализует все их свойства без адаптации.

Avalonia — самостоятельное desktop-окно и MVVM, не встроенная палитра nanoCAD. .NET 10 SDK выбран для воспроизводимой сборки; совместимость nanoCAD с .NET 10 не проверена. Для лицензированного хоста может понадобиться другой target framework или отдельный процесс и протокол.

## Последствия
+ Правила, генератор, UI и тесты работают без SDK; нет выдуманных членов платформенных классов.
− Настоящие DWG, ручки, лента, установка, реальная транзакция хоста и round-trip недоступны. Ни шаблон упаковки, ни скрипт preflight не регистрируют плагин. См. [руководство](NANOCAD_SDK_INTEGRATION_GUIDE.md).
