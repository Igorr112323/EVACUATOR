# Чек-лист сверки источников `[ПРОВЕРИТЬ ПО ТЕКСТУ ГОСТ]`

**Статус: ничего ниже не верифицировано.** Нужны официальные актуальные издания ГОСТ 12.4.026-2015 с Изм. №1, ГОСТ Р 12.2.143-2009, актуальная редакция ПП РФ №1479 и компетентный специалист. Даты актуальности, применимость и конкретные пункты заполняются **после** сверки; номера пунктов не выдуманы. Все сведения в JSON — демонстрационные.

- [ ] Для каждого из 30 кодов отдельно сверить точный код, название, область применения, ориентацию, рисунок и допустимые сочетания с официальными приложениями ГОСТ 12.4.026-2015 и изменением №1; проверить категории E/F/EC/P/W и цвет/носитель/кант. Источник каждого: `signs[].gostClauseRef`.
- [ ] Сверить диапазоны `minHeightMm`, `maxHeightMm`, `defaultHeightMm`, влияние масштаба, соотношения сторон, единый модуль R01/R02 и применимость одинаковой высоты разных носителей. Значения 8/10/15 мм сейчас учебные.
- [ ] Проверить учебные положения R03: обозначение и направление основного/запасного маршрута, сплошная/штриховая линия, цвет и толщина, размеры/частоту стрелок, исключения, способы привязки к реальной двери/лестнице. `snapToleranceMm`, `maxAutoSnapDistanceMm`, `arrowSpacingMm`, `arrowSizeMm`, `pathLineWeightMm` — эвристики, не нормативные утверждения.
- [ ] Проверить правила положения и числа маркеров R04. Центроид начальных точек не является подтверждённым местоположением.
- [ ] Проверить состав, названия, размеры и положение легенды R05 и рамки/шапки. `floorFrame*` и `localFrame*` из задания не являются точными размерами ISO A2/A3; эти параметры не утверждены по ГОСТ.
- [ ] Проверить R06: считать ли какие-либо перекрытия допустимыми, метод площади, границы, расположение объектов. `overlapThreshold = 0.15`, `duplicateToleranceMm`, сетка и число шагов — инженерные настройки, не норма.
- [ ] Проверить R07: утверждающую надпись, заголовок, текст памятки, актуальные номера 101/112, действующие требования ПП РФ №1479 и местные инструкции. Автовставленный шаблон не утверждает документ.
- [ ] Проверить разделы ГОСТ Р 12.2.143-2009 для размеров планов, элементов оформления, размещения и периодичности; зафиксировать точные пункты и редакции в новом утверждённом наборе данных.
- [ ] На реальном объекте подтвердить двери/препятствия, направление движения, размещение знаков, доступность, достоверность чертежа и все замечания после heal. Эта проверка кодом не выполняется.
