# ADR-003: Проверка и консервативное автолечение

**Статус:** принято, 2026-10-26; все нормы ниже `[ПРОВЕРИТЬ ПО ТЕКСТУ ГОСТ]`.

`INormRule` возвращает структурированные `ValidationIssue` с ID правила и объекта, severity, возможностью автоматического исправления, связанным объектом и маркированной ссылкой на проверку источника. `NormController` запускает семь правил над неизменяемым снимком. Индекс = `100 × (7 − число различных правил с ошибками) / 7`; предупреждения не уменьшают индекс, но никогда не означают разрешение к использованию. Количество ошибок может превышать семь. Валидация структуры не заменяет сертификацию.

`NormAutoFixer` строит новый снимок, «до/после», дифф по полям и список ручных действий. Нормализация размеров берёт пересечение диапазонов известных знаков; при отсутствии общего диапазона R02 остаётся ошибкой. Полные дубли сверяются **также с исходным снимком**, чтобы нормализация не уничтожила разные первоначальные объекты. Сдвиг носителя ищется по ограниченной сетке и остаётся помеченным для проверки. Маркер в центроиде начала маршрутов — только предположение. Стрелки включаются по порядку вершин; привязка допускается только в пределах порога и без вырождения/самопересечения/выхода за границы. Стены, двери и реальные пути в алгоритме отсутствуют. Переплетённые/неполные маршруты не проектируются автоматически.

Две группы послеобработки: ошибки, требующие ручного исправления, и предупреждения/изменения, которые обязан проверить специалист. Без изменений возвращается исходный снимок: повторная обработка идемпотентна и не создаёт фальшивую undo-транзакцию. В симуляторе весь heal фиксируется одним коммитом; при конкурирующей ревизии вычисление повторяется ограниченное число раз. Отчёт о неудаче не должен создавать впечатление отката уже завершённой транзакции.

Реальные требования ГОСТ, утверждение и все эвакуационные решения должны быть проверены по источникам и на объекте; `ComplianceScore` нельзя трактовать как нормативный процент. Ручная отмена не доказывает безопасного использования на настоящем объекте.
