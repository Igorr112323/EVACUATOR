# ADR-002: Параметрический векторный DSL

**Статус:** принято, 2026-10-26. Все рецепты учебные `[ПРОВЕРИТЬ ПО ТЕКСТУ ГОСТ]`.

## Представление
Внешний JSON содержит категорию, форму, цвет носителя, диапазон/модуль на бумаге, описание, флаг потенциального выхода и последовательность векторных примитивов. X нормализован по ширине носителя, Y — по высоте, толщина/радиус — по высоте. Прямоугольный носитель имеет отношение 2:1, прочие — 1:1. Начало — нижний левый угол, угол поворота против часовой стрелки; после масштаба и поворота прямоугольники становятся полигонами. `CircleSlash` — круг с красной диагональю, `EquilateralTriangle` — треугольный носитель.

- `Rect`: x/y/width/height.
- `Circle`: x/y/radius.
- `Polygon`/`Polyline`: массив нормализованных точек; полилинии требуется видимая обводка.
- `Arc`: центр x/y, radius, startAngleDegrees в `[0,360)`, ненулевой sweepAngleDegrees в `(-360,360)`, stroke и strokeWidth. Положительное направление — против часовой стрелки в Y-вверх; полный круг задаётся `Circle`. SVG выдаёт `path A`, Avalonia отображает сегментированную векторную аппроксимацию дуги.
- `Text`: x/y/text/fontSize. XML-текст экранируется; начертание шрифта и точные габариты зависят от системы.

`NormJsonShapeValidator` не даёт обязательным полям исчезнуть в default DTO, запрещает повторные JSON-ключи и ограничивает размеры наборов; `NormDatabaseValidator` проверяет enum, краски `#RRGGBB`/`none`, видимость, границы, размеры и взаимосвязи. JSON Schema является самостоятельной машинной спецификацией структуры; семантические проверки перекрываются, но полная эквивалентность валидаторов не заявляется. Дубликаты и неизвестные свойства отвергаются. Поправка заменяет полное определение знака по коду или добавляет новый, затем вся объединённая база проверяется. Частичная замена полей знака не поддерживается.

SVG не содержит растр и генерируется через `XmlWriter`; неизвестный тип не пропускается молча. Дополнения создаются вручную или через `tools/create_mvp_norms.py`; этот генератор демонстрационный и не является источником официальных рисунков. Ограничение: коллизии используют осевые bounding boxes повёрнутых носителей, не сложные реальные очертания. Художественные рецепты, цвета, формы, коды, описание и пункты стандартов подлежат экспертной сверке.
