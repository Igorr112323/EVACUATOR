# Runbook H01–H25: Windows + настоящий nanoCAD

**Все H01–H25: BLOCKED / NOT RUN.** В этом репозитории нет реального host-адаптера, загружаемого плагина или подтверждённой совместимости `net10.0` с nanoCAD. Запускать эту матрицу можно только после реализации и сборки bridge по официальному SDK выбранной лицензированной версии и после проверки условий использования. Это план, а не отчёт об испытаниях.

## Общие условия и фиксация

- Записать UTC, SHA исходников и SHA сборок/артефактов, версию/редакцию/сборку nanoCAD и SDK, Windows build, x64, .NET/CLR, локаль, источник нормбазы, режим лицензии **без секретов**. Копировать для испытаний только учебный DWG, не рабочие планы людей.
- Подготовить сценарий с 30 учебными знаками, основным и запасным маршрутом, маркером и легендой; создать его в настоящем host после появления реального адаптера. Исходные JSON/SVG/DXF не являются DWG.
- На каждый сценарий сохранить шаги, наблюдение, ожидаемый результат, PASS/FAIL/BLOCKED, причину отклонения, обезличенный host log и пути соответствующих DWG/скриншотов/PDF с SHA-256. Сохранять «до» и «после» раздельно; не публиковать лицензию, SDK или персональные данные. Результаты подписывает исполнитель испытаний.
- Точные команды, способы загрузки, имена API, ограничения транзакций, grips и сериализации определить по официальным примерам версии `[VERIFY_IN_NANOCAD_SDK]`; не использовать воображаемые сигнатуры. При отсутствии реализованной функции — BLOCKED, а не PASS.
- Автономный Simulator, тесты xUnit и отдельная Avalonia не заменяют ни одного H-теста. Все нормы, коды, изображения и размеры `[ПРОВЕРИТЬ ПО ТЕКСТУ ГОСТ]`; техническое прохождение не означает безопасности.
