## Раздел 2. Архитектура

```text
Evakuator.sln
├─ Domain       неизменяемые сущности, значения, геометрия и JSON
├─ Norms        конфигурация, структура/семантика, поправки, watcher
├─ Geometry     рецепты знаков, пути, рамки, легенда, SVG
├─ Validation   R01–R07, отчёт, безопасный healer и дифф
├─ CadAdapter   контракты, revision/undo-симулятор, команды, SDK gate
├─ UI           отдельное Avalonia-окно и MVVM
├─ CliDemo      входные JSON, before/after SVG и отчёты
└─ Tests        xUnit и сквозные проверки
```

Паттерны: чистая архитектура, value objects/immutable snapshots, Strategy для правил, repository/валидируемая публикация норм, MVVM, optimistic concurrency и bounded undo. Полный heal симулятора — одна undo-транзакция; ошибки подписчиков не отменяют уже выполненный commit. Платформенный API не выдуман: `NANOCAD_SDK` блокируется до реализации моста по лицензированному SDK. Шаблоны `packaging/` **не** являются устанавливаемыми пакетами или CUIX; `sdk-preflight.ps1` — диагностика, не регистрация, и в данной среде без `pwsh` не запускался. Подробнее: ADR-001–003 и руководство SDK.

## Раздел 5. Журнал самодиагностики

1. Среда не имела .NET и прямого доступа к CDN/NuGet: использованы проверенный по официальному хешу SDK и офлайн-источники; NuGet audit/отзыв сертификатов ограничены, как указано выше.
2. Первоначальному restore Avalonia не хватало WebAssembly-транзитивных пакетов; восстановление полного зеркала устранило `NU1101`.
3. Тесты выявили ошибку R02 при размерах по обе стороны модуля, повторную нормализацию и риск удаления объектов после изменения размеров: исправлены проверка размаха, идемпотентность и сравнение с исходным снимком.
4. Обработаны ложное самопересечение при последовательных дублях и невозможная привязка/обрезание вырожденного пути; включение стрелок, сдвиг и привязка помечаются для проверки. Слишком близкая к конечной стрелка устранена.
5. Структурная проверка базы усилена против `null`, пропущенных обязательных полей, повторных ключей и невидимых примитивов; проверена JSON Schema. Добавлены контракты транзакций, тесты конкурентных commits и изоляции исключений наблюдателей.
6. При добавлении CAD/UI тестов обнаружены ошибочные ожидания тестов относительно типа исключения и несуществующего кода W01; тесты исправлены на фактические контракт и W09. xUnit-анализатор `xUnit2031` исправлен, итоговая сборка чистая.
7. Для GUI отсутствовали дисплей/Xvfb/XKB, затем старые системные библиотеки мешали ICU. Временный виртуальный экран и изолированный набор библиотек позволили запустить окно; обнаруженное устаревшее сообщение после undo исправлено и покрыто тестом. Временные системные ссылки удалены.
8. При проверке повреждённого плана отсутствующая координата раньше могла превращаться в ноль, а `InvalidDataException` обходило обработчик CLI/UI. Добавлена строгая проверка координат/дублированных ключей и обработка ошибки; оба процесса возвращают код 1 без записи результатов.
9. Сборка с `NANOCAD_SDK` **намеренно** завершается `#error`; отрицательная проверка gate прошла. Это не успешная сборка плагина. Скрипт PowerShell и реальный SDK/хост не испытывались.
