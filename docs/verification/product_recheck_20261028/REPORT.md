Коммиты `68e8cde`, `9e9ffb04e8660fb3d780e9370862b06ec721e879` и `0ce8b316f355c4f11248be0da151ede7a17a4a59` отсутствуют в локальной базе объектов (`git cat-file -e` для каждого вернул 128). Старые отчёты, упоминающие сохранённый коммит `9e9ffb04…`, фиксируют историю прежней среды и **не** доказывают, что он доступен сейчас. Существующий статический скрипт поэтому использовал файлы рабочего дерева, сверенные с имеющимся манифестом, а не этот Git-объект.

При подготовке новых логов `git diff --cached --check` сначала нашёл лишнюю пустую строку в конце двух файлов; удалены только эти пустые строки, повторная проверка прошла — [git-staging-check.txt](git-staging-check.txt).
