# Аудит переносимого C# ядра — 29.10.2026

Аудит сочетает чтение исходников и указанные реальные Linux CI-тесты. Он не является security audit, нормативной экспертизой или исследованием host API. Снимок фактических зелёных тестов: `edbff4201c087b11ed20c583d8956bac75bd8910`; [TRX](github-final/trx/results.trx).

| Область | Проверка / наблюдение | Результат и остаточный риск |
|---|---|---|
| Domain и JSON | `PlanJson` запрещает неизвестные поля и проверяет структуру, идентичность и числовые значения; immutable records/arrays. | xUnit и повреждённый CLI JSON прошли. Это не полноценный JSON Schema validator и не проверка проектной корректности. Экстремальные конечные координаты могут приводить к переполнению промежуточных операций. |
| Norms | `JsonNormRepository` проверяет JSON и модель до публикации; watcher хранит last-known-good. | Тесты валидной/невалидной подгрузки и файлового события прошли на Ubuntu. События разных ОС/ФС различаются; исключения обработчиков `ReloadFailed` намеренно подавляются. Нет подтверждения официальных нормативов. |
| Geometry | `PolylineMath`, генераторы знаков/путей, безопасный XML writer. | Обратные смежные отрезки до исправления не выявлялись; [red](regression-red/test.log) → `4906514a3970de8609c96d5e3d5c0ceefa9f89b2` → [green](github-final/trx/results.trx). Численные допуски и сложная топология требуют дальнейшей экспертизы. |
| SVG legend | Прямоугольный носитель 2:1 был шире зарезервированной колонки. | [Red](legend-red/test.log) → `f9bf7527eb461878cb9f93905f3fe0f7f542c14c` → green; SVG повторно визуально осмотрен. Точность схем относительно ГОСТ не проверялась. |
| Validation | Семь учебных правил проверяют только представленную модель; сообщения должны быть воспроизводимы. | R01/R06 различались на en-US/ru-RU: [red](regression-red/test.log) → `7b15499442c85bf1969f9a608b31b6a70aa62528` → green. Значения и смысл правил не изменялись и не подтверждены нормативно. |
| Healer | Возвращает новый снимок, diff и ручные действия; проверяет собственные эвристики на границах/коллизиях/маршрутах. | Сценарий CLI и повторная обработка прошли; стены, двери, видимость и реальную проходимость он не доказывает. В худшем случае проверка пар знаков и поиск смещения могут быть дорогими. |
| CAD contract | `ICadDocumentContext` и in-memory атомарный снимок/ревизия/undo. | Шесть наследуемых контрактных тестов прошли **для Simulator**. Настоящих host-транзакций, сериализации DWG и хостового подкласса нет. |
| CLI | Входы и выходы передаются явно; каждый файл заменяется отдельно. | Положительный, неизвестная опция, повреждённая координата и идемпотентность прошли. Набор файлов не является единой транзакцией; пользователь должен указывать отдельный выходной каталог. |
| UI / SDK | UI — автономная Avalonia; `NANOCAD_SDK` блокируется в `SdkGate`. | Сборка и ViewModel xUnit на Linux; GUI в данном прогоне, Windows и nanoCAD не проверены. Блокировка не снималась. |
| Нагрузка / детерминизм | 200 знаков, 2 независимых heal и повторная обработка результата. | TRX фиксирует выход и время конкретного запуска, отсутствие изменений на повторе и идентичность результата; без обещания худшей производительности или эксплуатационной безопасности. |

Сторонние пакеты solution восстановлены из официального NuGet в CI; `NuGetAudit` не отключался. Доказательств полного перечня транзитивных лицензий, подписей, проверки на всех поддерживаемых платформах или готовности поставки нет.
